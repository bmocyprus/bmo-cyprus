# BMO Cyprus

BMO Cyprus is an engineering driven consulting practice operating across information technology operational technology security governance automation and managed security operations.

This repository acts as a public reference space for selected technical artefacts architectural approaches and governance examples that reflect how BMO engages with complex operational and critical infrastructure environments.

## Domains
- IT infrastructure and cloud architecture
- OT ICS IoT and critical infrastructure environments
- Security architecture risk governance and compliance
- Managed SOC and security operations
- Automation and operational workflows
- Business process NIS2 compliance design governance and assurance
- Legacy and lifecycle critical systems

## Principles
- Architecture before tooling
- Risk aware engineering decisions
- Operational continuity over vendor driven change
- Process clarity and accountability
- Documentation as a first class deliverable
